## Recommended Actions (prioritized)

### Must fix before shipping (Warnings)

1. **F-001 — PIT mutation testing skipped**: Either remove `-DskipPit` from the sonarcloud job or add a dedicated mutation-testing job. The Constitution §V and FR-001 both require mutation testing in CI. This is the highest-priority warning.

2. **F-005 — Feature flags not provisioned**: Add an `unleash-init` docker-compose service (mirror `kafka-init` pattern) to create the 6 flags via Unleash REST API after startup. Without this, T024 validation will fail and FR-019 is unmet.

3. **F-004 — UNLEASH_API_TOKEN no default**: Add the default value back to `application.yml` OR add a required `export UNLEASH_API_TOKEN=...` step to `quickstart.md`. Blocks local development for any new team member.

4. **F-002 — catch Throwable**: Change to `catch (Exception e)`. Low-risk change with high correctness value.

5. **F-006 — Wrong LLM in secrets-rotation.md**: Rename Claude → OpenAI keys. Documentation fix, but misleads operators managing production secrets.

6. **F-003 — Unleash latest tag**: Pin `unleash-server` to a specific version.

7. **F-007 — Staging-only K8s manifests**: Document the production deployment approach explicitly, or add a minimal Kustomize overlay for production namespace.
